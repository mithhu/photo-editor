# Photo Editor

A web-based photo editor built with React and Vite. Edit photos with adjustments, filters, crop, and more.

## Features

- **Upload** — Drag & drop or click to upload images
- **Adjustments** — Brightness, contrast, saturation
- **Crop** — Aspect ratios (Original, 1:1, 4:5, 16:9)
- **Rotate** — ±90°
- **Filters** — Vintage, Cinematic, B&W, and more
- **Export** — Download edited images as PNG

## Tech Stack

- React 19 + Vite 7
- Tailwind CSS v4
- Canvas API for image processing

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build

```bash
npm run build
npm run preview
```
